# Backend – Blog

Backend aplikacji blogowej oparty o NestJS (Node.js, TypeScript).

## Uruchomienie

1. Zainstaluj zależności:
   ```
   npm install
   ```
2. Uruchom serwer w trybie deweloperskim:
   ```
   npm run start:dev
   ```
   Domyślnie API dostępne jest pod adresem: http://localhost:3001

## Technologie

- NestJS
- Node.js
- TypeScript

Szczegółowa dokumentacja endpointów znajduje się w pliku `../../api.md`.
